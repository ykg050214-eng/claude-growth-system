## テンプレート1: 議事録生成

### システムプロンプト
```
あなたはプロフェッショナルな議事録作成アシスタントです。
提供された会議メモや発言録を元に、構造化された議事録を作成してください。
必ず以下の形式で出力してください。
```

### ユーザープロンプト
```
以下の会議メモから議事録を作成してください。

【会議情報】
- 会議名: {会議名}
- 日時: {日時}
- 参加者: {参加者リスト}

【会議メモ】
{会議メモの内容}

【出力形式】
# 議事録：{会議名}
**日時**: {日時}
**参加者**: {参加者}
**司会**: {司会者}

## 1. 議題
## 2. 討議内容
## 3. 決定事項
## 4. アクションアイテム
| 担当者 | タスク | 期限 |
## 5. 次回会議
```

### 使用モデル推奨: `claude-sonnet-4-6`
### 効果: 20分かかる議事録作成が約30秒に短縮

## テンプレート2: ビジネスメール生成

### システムプロンプト
```
あなたはビジネスライティングの専門家です。
状況に応じた適切なトーン・敬語・構成でメールを作成します。
```

### ユーザープロンプト
```
以下の条件でビジネスメールを作成してください。

【送信者情報】
- 所属: {会社名・部署}
- 名前: {氏名}

【送信先】
- 宛先: {相手の会社名・役職・氏名}
- 関係性: {初対面/継続取引先/社内など}

【メールの目的】
{例: 新製品のデモ依頼 / 納期延長のお詫び / 契約更新の確認 など}

【伝えたいポイント】
{箇条書きで記入}

【トーン】
{丁寧/フォーマル/カジュアル}

件名から本文まで完成形で出力してください。
```

### 使用モデル推奨: `claude-haiku-4-5-20251001`（高速・低コスト）
### 効果: メール1通の作成時間を平均15分→1分以下に短縮

## テンプレート3: 週次報告書生成

### システムプロンプト
```
あなたはビジネス文書作成の専門家です。
提供された業務メモから、上長への週次報告書を作成します。
数値・成果・課題を明確に整理してください。
```

### ユーザープロンプト
```
今週の業務内容から週次報告書を作成してください。

【基本情報】
- 報告者: {氏名} / {部署}
- 対象週: {YYYY年MM月DD日〜MM月DD日}

【今週やったこと（箇条書きでOK）】
{メモ}

【数値・成果】
{例: 商談件数3件、受注1件（120万円）など}

【来週の予定】
{メモ}

【課題・相談したいこと】
{メモ（なければ「なし」）}

---
以下の形式で出力してください：
# 週次報告書（{期間}）
## 今週の実績
## 定量成果
## 課題・リスク
## 来週の計画
## 相談・要望
```

### 使用モデル推奨: `claude-sonnet-4-6`

## テンプレート4: 提案書アウトライン生成

### システムプロンプト
```
あなたはコンサルタントとして、説得力のある提案書構成を設計します。
MECE（漏れなくダブりなく）な論理構造で、意思決定者が読みやすい提案書を作ります。
```

### ユーザープロンプト
```
以下の情報を元に提案書のアウトラインを作成してください。

【提案の概要】
- 提案内容: {何を提案するか}
- 提案先: {顧客名・担当者・役職}
- 予算規模: {概算}
- 提案の背景: {なぜこの提案が必要か}

【顧客の課題】
{箇条書きで記入}

【自社の強み・差別化ポイント】
{箇条書きで記入}

---
以下の構成でアウトラインを出力してください：
1. エグゼクティブサマリー（1ページ）
2. 現状の課題分析
3. 提案内容と解決策
4. 導入効果・ROI試算
5. 実施スケジュール
6. 費用・契約条件
7. 弊社の実績・事例
8. 次のアクション

各セクションに「含めるべき内容のポイント」を3〜5個記載してください。
```

### 使用モデル推奨: `claude-opus-4-6`（高精度が必要）

## テンプレート5: 会議アジェンダ自動生成

### システムプロンプト
```
あなたは会議ファシリテーターです。
目的から逆算した効率的な会議アジェンダを作成します。
```

### ユーザープロンプト
```
以下の情報から会議アジェンダを作成してください。

【会議情報】
- 目的: {この会議で決めたいこと・達成したいゴール}
- 時間: {60分/90分など}
- 参加者: {人数・役職}
- 前提: {前回の決定事項や背景があれば}

【必ず議論したいトピック】
{箇条書きで記入}

---
各議題に「目的・担当・時間配分・必要な事前準備」を含むアジェンダを作成してください。
会議冒頭で共有できるよう、1ページに収まる形式にしてください。
```

### 使用モデル推奨: `claude-haiku-4-5-20251001`

---

## 活用のコツ

1. **変数を{波括弧}で定義** — 再利用時に置換するだけでOK
2. **システムプロンプトでペルソナを固定** — 毎回同じ品質を担保
3. **出力形式を明示** — Markdown/表/JSON など形式指定で後処理が楽になる
4. **モデルを使い分ける** — 速度重視=Haiku / 品質重視=Opus / バランス=Sonnet
